# 腐蝕の館 — THE ROTTING MANOR

限られた弾、暗闇、倒れたふりをするゾンビ、鍵とアイテムを集めて進む探索。
古典的なサバイバルホラーの緊張感を、**肩越しTPS視点**で味わうブラウザゲームです。

- `index.html` 1ファイルだけで動きます（ビルド不要。Three.js r160 は CDN から読み込み）
- PC（キーボード＋マウス）、**USBゲームパッド**（BUFFALO BSGP1204P などの DirectInput パッドにも対応）、**スマホ・タブレット**（タッチ操作）で遊べます
- 3Dモデル（GLB）が1つも無くても、作り込んだ手続き生成キャラクターで最後まで遊べます

## 起動方法

ブラウザは `file://` で開いた HTML から GLB を読めないため、**ローカルサーバー経由**で開いてください。

### PC
`index.html`（と、使う場合は GLB ファイル）を置いたフォルダで次を実行します。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開き、タイトル画面をクリックすると始まります。

### スマホ・タブレット
1. PC で上と同じようにサーバーを起動します。
2. スマホを PC と同じ Wi-Fi につなぎ、ブラウザで `http://<PCのIPアドレス>:8000` を開きます。
3. 端末を**横向き**にして、タイトル画面をタップします（開始時に全画面化を試みます）。

> ゲームパッドをスマホにつなぐ場合、ブラウザによっては `localhost` 以外の http ではゲームパッドが使えません。その場合は GitHub Pages など https で公開してください。タッチ操作は http のままで動きます。

### インターネットに公開する（任意）
`index.html` は静的ファイルなので、GitHub Pages など任意の静的ホスティングにそのまま置けます。

## 3Dモデル（GLB）について

次の3ファイルを `index.html` と同じフォルダに置くと、自動で読み込みます（無くても遊べます）。

| 用途 | 既定のファイル名 |
|---|---|
| プレイヤー | `tactical+human+3d+model.glb` |
| ハンドガン | `銃.glb` |
| ゾンビ（ボスにも流用） | `zombie+3d+model.glb` |

- ファイル名に `+` や日本語が入っていると、環境によって読めないことがあります。`player.glb` / `gun.glb` / `zombie.glb` のような ASCII 名に変え、`index.html` 冒頭の `CONFIG.assets` を書き換えるのがおすすめです。
- 読み込んだモデルは自動で**身長 1.75m に揃え**、足元を床に合わせます。
- アニメーション名・ボーン名は**正規表現で自動探索**します（例：`idle` / `walk` / `run|sprint` / `aim` / `death|die` / `attack|bite`）。見つからない動作は別のクリップで代用するか、手続き的に動かします。探索結果はコンソールに表で出るほか、F1 のデバッグ表示でも確認できます。
- 銃は右手のボーン（`RightHand`、`hand_r`、`Hand.R` など）を探して取り付けます。
- **読み込みに失敗したモデルは手続き生成キャラクターに置き換えます**（ロード画面とタイトル画面に警告が出ます）。

### 手続き生成キャラクター
GLB が無いとき、または `CONFIG.characters = 'procedural'` にしたときに使われます。
- **プレイヤー**：戦闘服、タクティカルベスト（ポーチ・無線・肩のライト）、ニーパッド、ホルスター
- **ゾンビ**：個体ごとに服装（スーツ／シャツ／ベスト、研究所では白衣）、肌の色、傷や肋骨の露出、引きずる足が変わります
- **ボス**：肥大化した右腕と骨の爪、脈打って光る心臓、背中の骨棘
- 歩行・構え・リロード・攻撃・ダウン・起き上がりは関節を手続き的に動かします。ハンドガンとマグナムは別々のモデルです。

## 操作方法

### キーボード＋マウス
| 操作 | キー |
|---|---|
| 移動 | WASD（カメラ基準） |
| ダッシュ | Shift |
| 構える | 右クリック（押している間） |
| 射撃 | 構え中に左クリック（構えていないと撃てません） |
| リロード | R |
| 調べる／拾う／扉を開ける | E |
| アイテム | Tab（WASD で選択、E で使う・装備、Q で捨てる） |
| マップ | M |
| 武器切替 | 1：ハンドガン　2：マグナム（入手後） |
| 一時停止 | Esc（マウスの固定が外れると一時停止） |

### ゲームパッド
ブラウザが「標準配列」と認識するパッドはそのまま使えます。BSGP1204P のような DirectInput パッド（非標準配列）は、PS 配列を想定した次の割り当てが既定です。

| 操作 | ボタン |
|---|---|
| 移動 | 左スティック／十字キー |
| 視点 | 右スティック |
| 構える | R1 / L2 |
| 射撃 | ③(×) / R2 |
| 調べる・決定 | ②(○) |
| ダッシュ | ④(□) |
| リロード | ①(△) |
| アイテム | SELECT |
| マップ | L1 |
| 武器切替 | L3 / R3 |
| ポーズ | START |

- ブラウザは**パッドのボタンが一度押されるまでパッドを認識しません**。接続後、何かボタンを押してください。
- 押しても反応しないボタンがある場合は、タイトル右下またはポーズ画面の **「ゲームパッド設定」** から割り当て直せます。案内に従ってボタンを押していくだけです（右スティックの軸、上下反転も設定でき、パッドごとに保存されます）。
- 対応していれば振動します。構え中は照準補助が弱めに効きます。

### タッチ（スマホ・タブレット）
| 操作 | 方法 |
|---|---|
| 移動 | 画面左側をドラッグ（触れた場所にスティックが出ます） |
| 視点 | 画面右側をドラッグ |
| 構え | ［構え］で構える／解除（タップごとに切り替え） |
| 射撃 | ［射撃］。構えていなければ最初のタップで構えます。押したまま指をずらすと照準も動かせます |
| 調べる | ［調べる］（対象が近くにあると枠が光ります） |
| その他 | ［リロード］［走る］［武器］、右上にアイテム／マップ／ポーズ |

- 構え中は、照準の近くにいる敵の胴体へゆっくり吸い寄せる照準補助が効きます（ヘッドショットは自分で狙います）。
- アプリを切り替えたり画面をロックしたりすると自動で一時停止します。

### デバッグ用キー
| キー | 内容 |
|---|---|
| F1 | デバッグ表示（FPS、座標、ゾンビの状態、アニメ対応表、当たり判定の枠、パッドの入力値） |
| F2 / Shift+F2 | 銃の向きを Y軸 / X軸 で 90° ずつ回す（値が左下に出ます） |
| F3 | 無敵の切り替え |

## ゲームの進め方

洋館ホールから始まり、6つの部屋を探索して研究所の非常口から脱出するのが目的です。

- **弾は少なめです。** ハンドガンの弾はステージ全体で約60発。全部撃ってもボスは倒せません。
- **倒れたゾンビは油断できません。** 頭を撃ち抜いて倒さない限り、起き上がることがあります。倒れたゾンビに近づくと足を掴まれます。
- **アイテム欄は8枠しかありません。** 何を持ち歩くかよく考えてください。
- **体力**は右下（スマホでは左上）の心電図の色で分かります。緑＝Fine、黄＝Caution、赤＝Danger。グリーンハーブで回復します。
- **セーブ**はセーブ部屋のタイプライターで何度でもできます。死亡したら最後のセーブからやり直せます。セーブはブラウザにも保存され、タイトルの「つづきから」で再開できます。

<details>
<summary>攻略の流れ（ネタバレ注意）</summary>

1. 洋館ホール → 廊下へ。
2. 書斎で「所長の手紙」と「剣の鍵」を手に入れる。鍵を取ると……。
3. セーブ部屋で「予備ヒューズ」を拾い、タイプライターでセーブする。
4. 廊下の右端、剣のレリーフの扉を鍵で開けて地下研究所へ（停電中で非常灯のみ）。
5. 配電盤にヒューズをはめて電源を戻すと、奥の扉が開く。
6. 研究所の標本台の奥にマグナムがある（手紙にヒントがあります）。
7. 研究所深部で大型変異体と対決。ハンドガンはほとんど効かない。マグナムを使うこと。突進して壁にぶつかった直後が反撃のチャンス。
8. 撃破すると非常口のロックが外れる。脱出すると、クリアタイム・セーブ回数・ヘッドショット数が表示される。
</details>

## 設定（CONFIG）

`index.html` の `<script type="module">` 冒頭にある `CONFIG` で調整できます。主な項目は次のとおりです。

| 項目 | 内容 |
|---|---|
| `assets` | GLB ファイルのパス |
| `player.modelYaw` / `zombie.modelYaw` | モデルが後ろを向いているときは `Math.PI` |
| `gun.position` / `gun.rotation` | 右手に付けた銃の位置・向き（F2 で調べた値を入れる） |
| `gun.boneRegex` | 銃を付ける手のボーン名の探索パターン |
| `handgun` / `magnum` | 威力・装弾数・連射間隔・リロード時間・ばらつき |
| `zombie` | 体力、移動速度、視野、聴覚範囲、攻撃力、起き上がりの確率など |
| `boss` | 体力、速度、突進速度、ハンドガンのダメージ倍率、怯みのしきい値 |
| `camera` | 視野角、肩越しカメラの位置、マウス感度、上下の角度制限 |
| `characters` | `'auto'`（GLB があれば使う）／`'procedural'`（常に手続き生成キャラクター） |
| `gamepad` | デッドゾーン、視点速度、振動の有無 |
| `touch` | タッチの視点感度、照準補助の有無 |
| `mobile` | タッチ端末の描画解像度の上限、部屋ライトの影の有無 |
| `debug` | `true` で起動時からデバッグ表示 |

## 困ったときは

| 症状 | 対処 |
|---|---|
| キャラクターが手続き生成モデルのまま | `file://` で開いていないか確認し、ローカルサーバー経由で開く。ファイル名を ASCII にして `CONFIG.assets` を合わせる。ロード画面の警告文に原因が出ます |
| 銃の向きがおかしい | F2 / Shift+F2 で回し、左下に表示された値を `CONFIG.gun.rotation` に書く |
| モデルが後ろ向きに歩く | `CONFIG.player.modelYaw`（ゾンビは `CONFIG.zombie.modelYaw`）を `Math.PI` にする |
| ゲームパッドが反応しない | 接続後にパッドのボタンを一度押す。それでもだめなら「ゲームパッド設定」で割り当てる。BSGP1204P の MODE（アナログ）が OFF でも十字キーで動けます |
| 音が出ない | 画面を一度クリック／タップする（ブラウザは操作があるまで音を出しません） |
| 動作が重い | `CONFIG.mobile.pixelRatio` を下げる。PC では `renderer.setPixelRatio` の上限（既定 2）を下げる |
| 画面が暗すぎる | 恐怖演出として暗くしています。懐中電灯はカメラの向いている方を照らします |

ブラウザに保存されるデータ（localStorage）：
- `rotting-manor-save-v1`：セーブデータ
- `rotting-manor-pad-v1`：ゲームパッドの割り当て

## 技術メモ

- **構成**：`index.html` 1ファイル（HTML / CSS / JavaScript モジュール）
- **ライブラリ**：Three.js 0.160.0（importmap で CDN から読み込み）。アドオンは `GLTFLoader` と `SkeletonUtils` のみ
- **使っていないもの**：物理エンジン、ポストエフェクト、外部の音声ファイル。効果音と環境音はすべて WebAudio で合成しています
- **レベル**：タイルマップから生成し、壁・床・天井は部屋ごとに `InstancedMesh` にまとめています。全部屋を起動時に生成し、部屋の移動は表示の切り替えだけで行います
- **当たり判定**：円 vs AABB（XZ 平面）で、壁沿いに滑るように動きます。敵の追跡は A* 経路探索です
- **射撃判定**：カメラ中心のレイで狙点を決め、銃口から狙点までの間に壁があれば手前に着弾させる二段方式です。敵の当たり判定は見えない円柱（胴体）と球（頭）です
- **状態管理**：可変の状態はすべて `createInitialState()` が返すオブジェクトにまとめ、セーブは `structuredClone`、リトライは `resetGame()` で状態から再構築します
